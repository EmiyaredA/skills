# 提示词与一致性指南

> **助手注意**：下文 `gen_image.py` / `gen_video.py` 命令示例仅供理解参数字段；**助手不得直接运行这些脚本或调用 `/api/generate`**。任务写入 `plan.json` 后由用户在 `serve_review` UI 点「开始生成」。详见 [SKILL.md](../SKILL.md)「助手职责边界」。

## 图像提示词（角色 / 场景 / 分镜）

结构：**主体 + 外观细节 + 动作/姿态 + 环境 + 镜头 + 光线 + 风格**。

### 角色设定资料卡（人设图）——默认模板

**以 [templates/character-sheet.md](../templates/character-sheet.md) 为主**；`gen_image` 会在 `prompt` 后自动追加设定资料卡「要求」段（三视图 + 表情变化 + 服装装备分解 + 白底有条理排版）。

- **助手在 plan 里写 `prompt`**：
  - **无参考图**：写清身份锚点（外貌、服装、画风、可选的表情/装备要点），不要重复模板里的资料卡分区与排版要求。
  - **有参考图**（`references` / `--style-ref`）：**从简**——外观与画风交给参考图，只写 `gender`/`build` 及与参考图不同的改动点。
- **画风**：模板不含具体风格；用 `config.style`（全片统一）、`prompt` 或参考图表达。
- **用户有额外需求**：在 `prompt` 或 `config.style` 上补充；与模板冲突时以用户为准。

示例（无参考图）`prompt`：`成年女性，粉色长卷发，米色针织开衫配白衬衫与棕色长裤，温柔表情`  
示例（有参考图）`prompt`：`女`（`gender` 字段写 `女`；参考图由 `references` 传入）

有参考图 / `--style-ref` 时，脚本开头自动用「基于参考图，为同一原创角色制作官方设定资料卡…」并传参考图。

### 场景环境设定板（Environment Bible）——默认模板

**以 [templates/environment-bible.md](../templates/environment-bible.md) 为主**；`gen_image` 会在 `prompt` 后自动追加 Environment Bible「要求」段（六模块：主视觉/结构/镜头参考/延展环境/动线/视觉系统 + **严格空镜**）。

- **助手在 plan 里写 `prompt`**：
  - **无参考图**：写场景锚点（名称、主体空间、关联区域、时间天气、可选动线节点），不要重复六模块分区与空镜要求。
  - **有参考图**：**从简**——空间气质交给参考图，只写名称、改动点或额外区域/动线。
- **画风/品质对标**：模板不含 Pixar/吉卜力等具体对标；用 `config.style`、`prompt` 或参考图。
- **快速模式**：最少写场景名 + 主体空间 + 时间天气 + 风格（或 `config.style`），其余模板补全。

示例（无参考图）：`深夜便利店，收银区与货架通道，关联门外街道；雨后冷白荧光`  
示例（有参考图）：`深夜便利店，雨后`

- **分镜机位图**：写景别 + 机位 + 动作。把相关角色图/场景图作 `--reference` 传入以保持一致。例：`中景，过肩镜头，林夏推开玻璃门回头`。

景别与机位词：远景/全景/中景/近景/特写；平视/俯拍/仰拍/过肩/手持/推轨/环绕。

## 视频提示词

在图像描述基础上补充**运动与时间**：镜头运动（缓慢推进、横摇、跟拍）、主体动作的先后、节奏、情绪转折、是否有对白/音效。保持**单 clip 单一主要节拍**，时长越短越稳定。

**每个 clip 只写本镜内容**——不要写「接上镜继续…」「与下一镜同一机位延续…」；相邻 clip 靠阶段4 硬切，**无法保证丝滑衔接**。

例（5s clip）：`固定机位，林夏推开便利店门，回头对镜头微笑，霓虹灯在背后晕开。`

## 剧情拆 clip 与时长（助手必做）

收到用户一整段视频/剧情需求时：先拆节拍 → 每节拍 1 个 `shot` + 1 个 `clip`；边界选硬切友好切点；**禁止**相邻 clip 设计成须丝滑衔接的连续长镜头。

`duration` **推荐** 5/10/15 秒（写进任务字段，不进 prompt；API/UI 支持 4–15）：

| 秒数 | 典型内容 |
|------|----------|
| 5 | 单动作/单表情/空镜/一句短对白 |
| 10 | 一小段完整节拍 |
| 15 | 一个主节拍内信息稍多 |

信息量大 → **加 clip 数**，不要拉长单个 clip。默认不用 `continue_prev`。

## 跨角色画风统一（风格基准图）

一部短剧里所有角色要"像一个世界观里的人"。做法：**先定一个角色为画风基准，其余角色参考它生成。**

```bash
# 1) 先做女孩（基准），锁性别 —— 默认单张三视图合图，不要 --views；prompt 只写身份锚点
python scripts/gen_image.py --project P --type character --id char_01 --name 女孩 --gender 女 \
    --prompt "粉色长卷发，米色针织开衫配白衬衫与棕色长裤，温柔表情"

# 2) 男孩参考女孩出同款画风（有 style-ref，prompt 从简）
python scripts/gen_image.py --project P --type character --id char_02 --name 男孩 --gender 男 \
    --prompt "男，同参考画风" --style-ref char_01 --build "比女孩高一头"
```
`--style-ref` 会把基准图作参考，并自动追加"与参考图保持同一画风"。`--gender` 写进身份锚点，**防止性别生成错**（如男主出成女生）。

## 比例一致性（防止跨镜忽大忽小、人景失真）—— **强一致性关键**

1. 给每个角色一个**身高/体型**设定写进 `build`（如 `"build":"娇小，比男主矮一头"` / `"高挑"`），`character_anchor` 会注入并强调"相对比例跨镜一致"。
2. **更重要：在每条分镜 / 视频的提示词里都显式写明比例关系**，不要只靠锚点：
   - 人物之间：`男主比女主高约一头`、`女主身形娇小只到男主肩膀`。
   - 人物与场景/道具：`女主站立时头顶约到门框三分之二`、`小凳子高度约到女主膝盖`、`人物约占画面高度 70%`。
   - 同一组人物/场景在所有镜头里用**同一套比例措辞**，确保从分镜到视频始终一致。
3. 角色三视图 prompt 里也点明体型，方便后续镜头参照。

## 多角色同框：防止"角色消失 / 衣服对不上 / 变成两个同一人 / 比例不一致"

单张图像 API 只接受**一张**参考图。**分镜（多角色+场景）会自动把"各角色设定图 + 场景图"用 Pillow 拼成一张
「参考拼贴」**作为那一张参考图（`gen_image` 自动完成；无 Pillow 时回退为只用第一张）——这样模型能同时看到所有角色和场景。
**视频** API 原生支持多张参考图，所以最终视频的多角色一致性在视频阶段最强。两者都叠加上面的身份/比例锚点文字。

```bash
# 视频参考分镜图 shot_03 + 出场角色设定图（不用首尾帧）
python scripts/gen_video.py --project P --id clip_03 --characters char_01,char_02 \
    --prompt "天台上，男孩把便当递给女孩；男主比女主高一头" --shots shot_03 --sample
```
`--characters` / `--shots` 行为详见 [generation-modes.md](generation-modes.md)。

> 反馈里出现"性别错/衣服对不上/角色消失或重复"时：重做该镜，务必带上 `--characters`（视频）或 `--reference`（图像），并在 prompt 里写清"画面共 N 人：谁和谁，各自在做什么"。

## 一致性清单
- 角色：复用三视图作参考；新角色用 `--style-ref` 对齐画风，`--gender`/`--build` 锁身份与比例。
- 多角色镜头：视频用 `--characters`；分镜用 `--characters` + 场景（多图自动拼贴）。
- 跨镜：视频以分镜图作参考（`--shots`）。
- 画幅与风格：统一 `ratio`；`config.style` 自动追加到每条 prompt（无需手写）。

> 配置信息（画幅、分辨率、时长、样片/成片）由任务字段或设置面板控制，**不要写进提示词**。人物/场景大小比例属于提示词内容。

## 反面清单
- 一个 clip 塞多个主节拍 → 拆 clip 或加长到 10s/15s 但仍只保留一个主节拍。
- 相邻 clip 设计成连续长镜头上下段 → 改独立硬切镜头。
- 视频混用首/尾帧 + 参考图 → API 400；本 skill 只用参考图驱动。
- 样片就上 1080p → 先 480p 样片确认。

视频模式与 API 约束详见 [generation-modes.md](generation-modes.md)。
