# 提示词与一致性指南

## 图像提示词（角色 / 场景 / 分镜）

结构：**主体 + 外观细节 + 动作/姿态 + 环境 + 镜头 + 光线 + 风格**。

- **角色三视图**：固定服装、发型、配饰、年龄、体态等"身份锚点"；脚本会自动追加正/侧/背与"设定集、纯色背景、统一光照"。例：`28岁男性侦探，深灰风衣，左眉疤痕，冷峻表情`。
- **场景图**：**只写环境，不要写人物/动作**（场景=空镜，人物留给分镜）。写清地点、时间、天气、关键道具、色调。例：`深夜便利店内部，冷白荧光，货架反光，玻璃门外霓虹`。脚本对 scene 会自动追加"画面无人物"约束作兜底。
- **分镜机位图**：写景别 + 机位 + 动作。把相关角色图/场景图作 `--reference` 传入以保持一致。例：`中景，过肩镜头，林夏推开玻璃门回头`。

景别与机位词：远景/全景/中景/近景/特写；平视/俯拍/仰拍/过肩/手持/推轨/环绕。

## 视频提示词

在图像描述基础上补充**运动与时间**：镜头运动（缓慢推进、横摇、跟拍）、主体动作的先后、节奏、情绪转折、是否有对白/音效。保持单镜头单一主要动作，时长越短越稳定。

例：`固定机位，林夏推开便利店门，回头对镜头微笑，霓虹灯在背后晕开，2秒后转身走入店内`。

## 跨角色画风统一（风格基准图）

一部短剧里所有角色要"像一个世界观里的人"。做法：**先定一个角色为画风基准，其余角色参考它生成。**

```bash
# 1) 先做女孩（基准），锁性别
python gen_image.py --project P --type character --id char_01 --name 女孩 --gender 女 \
    --prompt "黑长直，校服，二次元3D渲染风格" --views front,side,back

# 2) 男孩参考女孩出同款3D画风（--style-ref 接受角色 id 或图片路径）
python gen_image.py --project P --type character --id char_02 --name 男孩 --gender 男 \
    --prompt "短发，校服" --style-ref char_01 --views front,side,back
```
`--style-ref` 会把基准图作参考，并自动追加"与参考图保持同一画风"。`--gender` 写进身份锚点，**防止性别生成错**（如男主出成女生）。

## 比例一致性（防止跨镜忽大忽小、人景失真）—— **强一致性关键**

1. 给每个角色一个**身高/体型**设定写进 `build`（如 `"build":"娇小，比男主矮一头"` / `"高挑"`），`character_anchor` 会注入并强调"相对比例跨镜一致"。
2. **更重要：在每条分镜 / 视频的提示词里都显式写明比例关系**，不要只靠锚点：
   - 人物之间：`男主比女主高约一头`、`女主身形娇小只到男主肩膀`。
   - 人物与场景/道具：`女主站立时头顶约到门框三分之二`、`小凳子高度约到女主膝盖`、`人物约占画面高度 70%`。
   - 同一组人物/场景在所有镜头里用**同一套比例措辞**，确保从分镜到视频始终一致。
3. 角色三视图 prompt 里也点明体型，方便后续镜头参照。

## 多角色同框：防止"角色消失 / 衣服对不上 / 变成两个同一人 / 比例不一致"

单张图像 API 只接受**一张**参考图。**分镜（多角色+场景）会自动把"各角色设定图 + 场景图"用 Pillow 拼成一张
「参考拼贴」**作为那一张参考图（`gen_image` 自动完成；无 Pillow 时回退为只用第一张）——这样模型能同时看到所有角色和场景。
**视频** API 原生支持多张参考图，所以最终视频的多角色一致性在视频阶段最强。两者都叠加上面的身份/比例锚点文字。

```bash
# 视频参考分镜图 shot_03 + 出场角色设定图（不用首尾帧）
python gen_video.py --project P --id clip_03 --characters char_01,char_02 \
    --prompt "天台上，男孩把便当递给女孩；男主比女主高一头" --shots shot_03 --sample
```
`--characters` 会：① 把每个角色的性别/发型/服装/瞳色/体型等身份锚点重申进 prompt（强约束"不得增减或替换角色"）；② 把各角色设定图都作参考图。`--shots` 把分镜图作参考。分镜机位图 `gen_image --type shot --characters ...` 同理（单参考图时多张会拼成参考拼贴）。

> 反馈里出现"性别错/衣服对不上/角色消失或重复"时：重做该镜，务必带上 `--characters`（视频）或 `--reference`（图像），并在 prompt 里写清"画面共 N 人：谁和谁，各自在做什么"。

## 一致性清单
- 角色：每次都复用同一份三视图/正面图作参考，固定身份锚点措辞；新角色用 `--style-ref` 对齐画风，`--gender` 锁性别。
- 多角色镜头：视频用 `--characters` 注入全部角色锚点+参考图；prompt 写清人数与各自动作。
- 场景：复用场景图作参考，保持色调与光源描述一致。
- 跨镜：视频以分镜图作参考（`--shots`），构图/内容随分镜走（见 [generation-modes.md](generation-modes.md)）。
- 画幅与风格：整部短剧统一 `ratio` 与风格词。**`state.config.style`（设置面板「视觉风格」）会自动追加到每条图像/视频提示词**（如「整体视觉风格：日系治愈手绘风，全片统一」），无需在每条 prompt 里手写；想统一改风格只改这一处。

## 反面清单（容易翻车）
- 一个镜头塞多个主要动作 → 拆成多个 clip。
- 角色数量过多（>4）→ 一致性骤降。
- 视频混用首/尾帧 + 参考图 → API 报 400「首尾帧和参考素材不能混用」；本 skill 只用参考图驱动。
- 样片就上 1080p → 浪费积分，先 480p。
