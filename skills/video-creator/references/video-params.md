# 视频参数

AI 视频生成的默认约束。可在 `state.json` 的 `brief` 中按项目调整。

## 推荐默认值

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 画幅比例 | `16:9` | 竖屏/社交内容用 `9:16` |
| 单集时长 | 5–15 秒 | 每次 API 调用 = 一集 |
| 分辨率 | 720p–1080p | 取决于 API 提供商 |
| 帧率 | 24 fps | 电影感默认；社交内容可用 30 fps |

## 画幅比例指南

| 比例 | 适用场景 |
|------|----------|
| `16:9` | YouTube、演示、横屏 |
| `9:16` | TikTok、Reels、Shorts |
| `1:1` | Instagram 信息流 |
| `4:3` | 经典 / 复古风格 |

## 剧集模型

- **一次 `generate_video.py` 调用 = 一集**（一个视频文件）
- 每集使用一个或多个**已批准**的分镜节拍
- 续写时追加新节拍 → 新剧集（`ep02`、`ep03`……）
- 未经用户要求，不得合并多集

## Prompt 组装方式

`generate_video.py` 从以下内容构建视频 prompt：

1. 简报：标题、风格、情绪
2. 选定节拍：场景、角色、动作、对白

节拍动作应简洁、可拍摄 — 每格一个清晰动作。

## 文件命名

```
output/ep01.mp4
output/ep02.mp4
output/qa/ep01/frame_001.jpg   # 由 extract_keyframes.py 生成
```

## 提供商建议

- 若视频 API 支持图生视频，传入 `reference_images`
- `duration` 需匹配提供商上限（多数限制 5–10 秒）
- 生成失败时，先减少节拍数量或缩短时长再重试

## 生成后 QA 检查清单

1. 对输出视频运行 `extract_keyframes.py`
2. 将关键帧与分镜预览图对比
3. 检查：角色一致性、场景连贯性、动作匹配度
4. 发现问题时修订分镜并重新生成 — 不得跳过用户确认
