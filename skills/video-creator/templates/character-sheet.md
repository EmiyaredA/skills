# 角色设定资料卡（人设图）默认模板

阶段 1 生成 `characters` 时，**以本模板为主**。`gen_image.py` 会在用户写的 `prompt` 之后自动追加下方「要求」段落（**设定资料卡的布局与输出约束**；具体画风不含在模板内）。

## 设计目标

制作类似**官方设定资料**的角色资料卡，单张合图包含：

- **三视图**：正面、侧面、背面（全身站姿，比例一致）
- **面部表情变化**：同一角色的多种表情（如平静、微笑、惊讶等）
- **服装与装备分解**：外衣、内搭、鞋帽、配饰、道具等细节局部展示
- **整体排版**：白色背景、分区清晰、有条理的设定集插画资料风格

用户有额外需求可在 `prompt` / `config.style` 上叠加；**与模板冲突时以用户为准**。

## 优先级

1. **默认**：使用本模板（资料卡分区、三视图、表情、服装分解、白底排版等）。
2. **画风从哪来**：参考图、`prompt` 里的风格描述、或 `config.style`（脚本末尾自动追加「整体视觉风格」）。
3. **用户补充**：如指定表情种类、要展示的装备件数、更写实/更 Q 等 → 写入 `prompt` 或 `config.style`。

## 助手写什么（plan `prompt`）

**不要重复**模板里已有的分区构图、白底排版、三视图/表情/服装分解等要求。

### 无参考图

写清身份锚点，并视需要补充画风：

- 性别、年龄感、脸型、发型、发色、瞳色
- 服装结构、颜色、鞋子、配饰、标志性装备
- 画风（若未在 `config.style` 里统一设定）
- 可选：希望重点展示的表情或装备（如「附带背包与工牌分解」）

示例：`成年女性，粉色长卷发，米色针织开衫配白衬衫与棕色长裤，温柔气质，日系插画风格`

### 有参考图（`references` / `--style-ref`）

**外观与画风以参考图为准，prompt 从简**——脚本会传参考图，并自动用「基于参考图，为同一原创角色制作官方设定资料卡…」开头。

只补充参考图看不出的、或需要强约束的字段：

- `gender`（必写，防性别漂移）
- `build`（身高/体型）
- 与参考图不同的改动点，或额外要分解展示的装备

示例（用户上传参考图）：`女`（配合 `"gender":"女"`）  
示例（`--style-ref`）：`男，同参考画风`（配合 `"gender":"男"`、`build`）

## 自动追加的模板（脚本 `gen_image`）

有参考图时开头为「基于参考图，为同一原创角色制作官方设定资料卡式角色设定图」；无参考图时为「为原创角色制作官方设定资料卡式角色设定图」。

```
要求：
整体为官方设定资料卡式排版：白色背景，分区清晰、布局有条理，设定集插画资料风格，平面均匀光照，轻微阴影，禁止复杂场景背景。
第一区横向陈列完整三视图：正面、侧面、背面全身站姿，比例一致。
第二区展示同一角色的面部表情变化（如平静、微笑、惊讶等，保持同一脸型、发型与发色）。
第三区分解陈列服装与装备细节（外衣、内搭、鞋帽、配饰、道具等各部位拆分展示，颜色与材质与主视图一致）。
全图必须是同一个原创角色，各分区外观保持一致。
不要添加文字，不要水印，不要多余无关人物，不要擅自改动服装设计。
```

**不含**具体细分画风（Q 版、写实、3D 等）——由参考图 / `prompt` / `config.style` 控制。

默认输出为**单张合图**（资料卡全页），不要用 `--views` 分张（除非用户明确要求）。
