# 角色三视图（人设图）默认模板

阶段 1 生成 `characters` 时，**以本模板为主**。`gen_image.py` 会在用户写的 `prompt`（身份锚点）之后自动追加下方「要求」段落。

## 优先级

1. **默认**：使用本模板（含默认 Q 版画风）。
2. **用户有额外需求**：在 `prompt` 或 `config.style` 上**叠加**补充（如「戴圆框眼镜」「校服改为运动服」）。
3. **与模板冲突时以用户为准**：例如用户要写实/3D/国风而非 Q 版 → 写入 `config.style` 或 `prompt` 明确画风，脚本会跳过模板里的默认 Q 版句，改由 `config.style` 统一控制全片视觉。

## 助手写什么（plan `prompt`）

分两种情况，**不要重复**模板里已有的构图/背景/Q 版要求：

### 无参考图

写清身份锚点，越具体越稳：

- 性别、年龄感、脸型、发型、发色、瞳色
- 服装结构、颜色、鞋子、配饰、标志性特征

示例：`成年女性，粉色长卷发，米色针织开衫配白衬衫与棕色长裤，温柔表情`

### 有参考图（`references` / `--style-ref`）

**外观以参考图为准，prompt 从简**——不必逐条复述发型、服装、颜色等参考图里已经能看出的细节。脚本会传参考图，并自动用「根据参考图生成同一原创角色…」开头。

只补充参考图看不出的、或需要强约束的字段：

- `gender`（必写，防性别漂移）
- `build`（身高/体型，参考图难判断时）
- 与参考图不同的改动点（如「把开衫换成校服」「表情更严肃」）
- 用户额外要求（与模板不冲突的叠加项）

示例（用户上传参考图）：`女`（配合 `"gender":"女"`）  
示例（`--style-ref` 对齐另一角色画风）：`男，同参考画风`（配合 `"gender":"男"`、`build`）

## 自动追加的模板（脚本 `gen_image`）

有参考图时开头为「根据参考图生成同一原创角色的角色设定三视图」；无参考图时为「生成原创角色的角色设定三视图」。

```
要求：
第一排横向展示完整三视图：正面、侧面、背面，全身站姿，比例一致。
三张视图必须是同一个角色，保持相同的脸型、发型、发色、眼睛颜色、体型、服装结构、服装颜色、鞋子和配饰。
使用干净白色背景或浅灰背景，平面均匀光照，轻微阴影，禁止复杂背景。
角色为二次元Q版风格，精致手办质感，软萌比例，线条干净。（仅当未设置 config.style 时追加）
不要添加文字，不要水印，不要多余人物，不要改变服装设计。
```

默认输出为**单张合图**（正/侧/背横排），不要用 `--views` 分张三张（除非用户明确要求）。
