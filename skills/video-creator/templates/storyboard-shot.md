# 分镜机位图（shot）默认模板

阶段 2 生成 `shots` 时，**以本模板为主**。`gen_image.py` 会在用户写的 `prompt` 之后自动追加「要求」段落（**分镜静帧与参考图一致性约束**；具体画风不含在模板内）。

## 设计目标

输出**单幅电影分镜静帧**（storyboard frame），用于后续视频生成的构图与身份锚点：

- **角色**：与参考人设图的脸型/发型/服装/体型**严格一致**
- **场景**：与参考 Environment Bible 的空间/道具/光线**严格一致**
- **构图**：单一机位、单一景别、本镜动作；**不是**设定资料卡或场景合图排版

## 参考图机制

plan 任务务必写 `characters` + `scene`（多角色用逗号分隔）。服务会自动注入：

1. 各角色设定图 + 场景图
2. 多图时拼成一张「参考拼贴」喂给 API（需 Pillow；否则回退第一张）

脚本还会注入 `character_anchor` 文字锚点（性别/身份/比例）。

## 助手写什么（plan `prompt`）

**不要重复**模板里已有的一致性约束、禁止分格/拼贴输出等要求。

### 无参考图（少见，阶段1 未完成时）

写清：景别 + 机位 + 出场人物动作 + 人与场景/人物间比例 + 关键道具。

示例：`中景固定机位，林夏推门进入便利店，男主在柜台后抬头；林夏身形娇小，人物约占画面高度 65%`

### 有参考图（常规，阶段1 人设/场景已完成）

**外观/空间/画风交给参考图，prompt 从简**——只写本镜**机位、动作、情绪、比例关系**：

- 景别：远/全/中/近/特写
- 机位：平视/俯/仰/过肩/固定/横摇感
- 动作与表情（谁做什么）
- 人物间、人与场景的大小关系（与 `build` 一致）

示例：`中景略俯，两人坐地翻找纸箱，女孩被旧照片逗笑，男孩探头看；男孩比女孩高一头，人物约占画面 70%`

**必须**在 plan 里写 `characters` 与 `scene`，不要只在 prompt 里写角色外貌。

## 自动追加的模板（脚本 `gen_image`）

有参考图时强调「严格依照参考的人设图与场景图」；多图拼贴时说明参考图为横向拼贴。

```
要求：
本图是单幅电影分镜静帧，不是角色设定资料卡，不是 Environment Bible 分格合图。
角色一致性：每个出场角色的脸型、发型、发色、瞳色、服装、配饰、身高体型必须与参考人设图完全一致；
不得增减角色、不得替换成他人、不得性别错配、不得服装漂移。
场景一致性：空间布局、关键道具、材质、色调、时间天气与光线必须与参考场景图一致，不得擅自改结构或换场景。
画风一致性：渲染风格与参考图保持同一世界观。
构图：只呈现本 prompt 的单一机位与景别；画面内人物数量与出场名单一致。
不要输出拼贴/分格/资料卡排版；不要添加文字或水印。
```

**不含**具体细分画风——由参考图 / `prompt` / `config.style` 控制。
