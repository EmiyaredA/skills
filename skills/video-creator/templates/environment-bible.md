# 场景环境设定板（Environment Bible）默认模板

阶段 1 生成 `scenes` 时，**以本模板为主**。`gen_image.py` 会在用户写的 `prompt` 之后自动追加下方「要求」段落（**Environment Bible 六模块布局与空镜约束**；具体画风不含在模板内）。

## 设计目标

制作用于 **AI 视频/动画/短片** 的**空间统一系统**（不是普通效果图），单张合图分区包含：

| 模块 | 内容 |
|------|------|
| **1 世界观主视觉** | 主体空间 + 周边关联区域，真实使用痕迹，时间/天气氛围 |
| **2 空间结构图** | 轴测/等距结构示意：布局、家具设施、采光、动线（无人物） |
| **3 空间镜头参考** | 全景 / 中景 / POV / 动线 / 情绪镜头，跨镜头材质灯光一致 |
| **4 延展环境系统** | 外部/周边环境，与主空间统一世界观 |
| **5 镜头动线系统** | 贯穿式路径节点串联，支持长镜头跟拍 |
| **6 视觉风格定义** | 建筑语言、材质、灯光、摄影、色彩、焦段景深、时间天气 |

**严格空镜**：不出现人物（人物留给分镜阶段）。

用户有额外需求可在 `prompt` / `config.style` 上叠加；**与模板冲突时以用户为准**。

## 优先级

1. **默认**：使用本模板（六模块分区、空镜、电影级排版等）。
2. **画风/品质对标**：参考图、`prompt`、`config.style`（脚本末尾自动追加「整体视觉风格」）。
3. **用户补充**：如指定关联区域名称、动线节点、对标气质（写实/A24/吉卜力等）→ 写入 `prompt` 或 `config.style`。

## 助手写什么（plan `prompt`）

**不要重复**模板里已有的六模块分区、空镜、电影排版等要求。

### 无参考图

写清场景锚点，并视需要补充风格/对标：

- 场景名称与类型（住宅、商业、自然、科幻等）
- 主体空间 + 2–4 个周边关联区域（模块1）
- 时间、天气、光线、关键道具、色调
- 可选：动线节点 3–5 个（模块5）、风格对标（若未在 `config.style` 设定）

示例：`深夜便利店，主体为收银区与货架通道，关联玻璃门外街道与后巷；雨后地面反光，冷白荧光；动线：门口→货架→收银台→后巷`

### 有参考图（`references`）

**空间气质与布局以参考图为准，prompt 从简**——脚本会传参考图，并自动用「基于参考图，为同一原创场景制作 Environment Bible…」开头。

只补充参考图看不出的、或需要强约束的字段：

- 场景名称
- 与参考图不同的改动点（如「改为黄昏」「增加雨后湿地面」）
- 额外要展示的关联区域或动线节点

示例（用户上传参考图）：`深夜便利店，雨后`  
示例（快速模式，仅 4 项）：场景名 + 主体空间 + 时间天气 + 风格关键词

## 自动追加的模板（脚本 `gen_image`）

有参考图时开头为「基于参考图，为同一原创场景制作完整的环境设定板（Environment Bible）」；无参考图时为「为原创场景制作…」。

```
要求：
用途：用于后续分镜/视频的空间统一系统……（六模块分区排版）
模块1–6：（世界观主视觉 / 空间结构 / 镜头参考 / 延展环境 / 动线 / 视觉系统）
严格空镜：不要出现任何人物、角色或人影；不要添加文字，不要水印。
```

**不含**具体品质对标（Pixar、吉卜力等）——由参考图 / `prompt` / `config.style` 控制。

默认输出为**单张合图**（Environment Bible 全页），画幅默认跟随项目 `config.ratio`（推荐 16:9）。

## 快速用法（助手）

若用户只需快速出图，plan `prompt` 最少写这 4 项即可，其余由模板补全：

1. 场景名称
2. 主体空间（一句话）
3. 时间/天气氛围
4. 风格关键词（或已在 `config.style`）
